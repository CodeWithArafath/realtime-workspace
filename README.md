# Real-Time B2B Collaboration Workspace

A Slack/Notion-inspired collaboration platform built using the MERN stack with real-time communication.

## 🚀 Features

### Authentication
- User registration
- Secure password hashing with bcrypt
- JWT based authentication
- Protected routes

### Workspace Management
- Create workspaces
- Manage workspace members
- Role-based access control

### Channels
- Create channels
- View workspace channels
- Delete channels

### Real-Time Communication
- Real-time messaging using Socket.IO
- Channel-based communication
- Typing indicators

### Production Features
- Redis integration
- Docker support
- GitHub Actions CI/CD
